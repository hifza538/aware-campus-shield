# Demo Screenshots

This folder contains placeholder screenshots for the PhishAware phishing test feature.

## Screenshots Included

1. **quiz-landing.png** - Landing page for the phishing test
2. **quiz-running.png** - Quiz in progress showing email and answer options  
3. **quiz-feedback.png** - Immediate feedback after answering a question
4. **quiz-results.png** - Final results screen with score and review

## Usage

These screenshots can be used in documentation, README files, or for demonstration purposes.

To replace with actual screenshots:
1. Take screenshots of the actual application
2. Optimize images for web (recommended: PNG format, max 1920px width)
3. Replace the placeholder files with the same names

## File Naming Convention

- Use descriptive names with hyphens
- Include the feature name prefix (quiz-)
- Use lowercase letters
- Save as PNG for UI screenshots
